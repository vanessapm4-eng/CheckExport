# CheckExport

Sistema de información web para la gestión y verificación del cumplimiento de requisitos fitosanitarios en la exportación de flores naturales.

## Descripción

CheckExport es una aplicación web diseñada para ayudar a productores y exportadores de flores a verificar el cumplimiento de los requisitos fitosanitarios exigidos por el Instituto Colombiano Agropecuario (ICA) y los estándares internacionales de la Convención Internacional de Protección Fitosanitaria (IPPC).

La plataforma centraliza la información necesaria para el proceso fitosanitario, facilitando el seguimiento de obligaciones sanitarias, el control de plagas, la trazabilidad y la preparación para inspecciones oficiales previas a la exportación.

---

## Objetivo General

Desarrollar una aplicación web tipo checklist de verificación fitosanitaria para la gestión del cumplimiento de los requisitos sanitarios exigidos en la exportación de flores naturales hacia mercados internacionales, en conformidad con la normativa vigente establecida por el ICA y los estándares definidos por la IPPC.

---

## Características Principales

- Checklist fitosanitario digital.
- Seguimiento del nivel de cumplimiento.
- Sistema de alertas automáticas.
- Registro y monitoreo de plagas.
- Registro de aplicaciones fitosanitarias.
- Indicadores de riesgo sanitario.
- Generación de reportes en PDF.
- Gestión de usuarios.
- Gestión de predios productores.
- Gestión documental.
- Dashboard con indicadores fitosanitarios.

---

## Alcance del Proyecto

El sistema permite:

- Validar el cumplimiento de la Resolución ICA 2191 de 2024.
- Gestionar el registro sanitario de predios productores.
- Controlar la trazabilidad del cultivo.
- Monitorear plagas reglamentadas.
- Registrar aplicaciones fitosanitarias autorizadas.
- Dar seguimiento a inspecciones fitosanitarias.
- Gestionar certificados fitosanitarios.
- Generar reportes de cumplimiento.

### No incluye

- Procesos aduaneros o arancelarios.
- Gestión logística de transporte.
- Negociaciones comerciales.
- Procesos financieros o contables.
